# go-dir

目录相关的小工具，整理磁盘、找大文件、看类型分布时用得上。

功能：

- 找大文件：按体积排序列出最大的 N 个，可用 `-min` 限定最小体积（支持 K/M/G/T 单位，如 `-min 2M`）
- 类型统计：按扩展名统计各类文件数量，并给出文件总数
- 目录树：像 `tree` 命令那样打印目录结构，可用 `-d` 限制深度
- 空目录：递归找出所有不含内容的空目录，清理磁盘时用得上

```bash
# 最大的 10 个文件
go run . big .

# 只关心大于 2MB 的，取前 5
go run . big -top 5 -min 2M .

# 扩展名分布
go run . types .

# 打印目录树，深度 2
go run . tree -d 2 .

# 找出空目录
go run . empty .
```
